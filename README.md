# 예종 음악 놀이터

예종피아노음악학원 초등학생(1~6학년)을 위한 음악 게임 모음입니다. 선생님 아이패드에서 쓰는 것을 기준으로 만들었고, 휴대폰에서도 동작합니다.
빌드 없는 정적 파일이라 GitHub Pages에 그대로 올려 씁니다.

## 게임 20개 (분류 탭 · 학년별 난이도)

| 분류 | 게임 |
|---|---|
| 🎼 악보 | 계이름 맞히기 · 몇 박일까요? · 건반 찾기 · 음악 기호 퀴즈 · ⚡ 계이름 스피드(30초) |
| 👂 듣기 | 높은 소리 낮은 소리 · 소리 듣고 계이름 · 크게? 작게?(셈여림) · 밝은 음악? 슬픈 음악?(장조·단조) · 빠르게? 느리게? · 올라가요? 내려가요?(멜로디 방향·음정) · 노래 제목 맞히기(저작권 없는 동요) |
| 🎮 리듬·놀이 | 리듬 따라치기 · 건반 따라치기 · 🃏 짝 맞추기(기호↔뜻) · 🧩 마디 채우기 / 박수 세기 |
| 🎨 만들기 | 🎨 음표 색칠하기(음악 그림) · 🖌️ 소리 그림판 · 🎶 멜로디 만들기 · 🥁 비트 만들기 |

모든 게임은 음악 개념을 다루고, 1~3학년 / 4~6학년 난이도가 따로 있습니다(예: 계이름 맞히기 — 저학년 도~도 색깔 힌트, 고학년 낮은음자리표·덧줄).
만들기 게임은 점수 대신 "완성!"을 누르면 별을 받습니다.

별 1~3개, 연속 정답 콤보, 게임·학년별 최고 기록(기기에 저장)이 있습니다. 소리는 브라우저에서 합성합니다.

## 15분 놀이 시간 제한

- 게임을 처음 누른 순간부터 15분이 지나면 "오늘 놀이 시간 끝!" 화면으로 잠깁니다.
- 시작 시각을 기기에 저장해서 **새로고침하거나 다시 열어도 초기화되지 않습니다.**
- **🔄 시간·별 초기화(선생님)**: 홈 화면 아래 버튼 → 비밀번호 입력 → 놀이 시간과 별 기록을 모두 처음으로(다음 학생).
- **선생님 해제**: 잠금 화면에서 선생님 비밀번호(4자리)를 누르면 다음 학생이 새로 15분을 시작합니다(별 기록도 초기화). 비밀번호는 `js/app.js`의 `TEACHER_PIN`.

## 실행

`index.html`을 열거나 `python3 -m http.server 8000`. 악보는 [VexFlow](https://www.vexflow.com/)(CDN), 글꼴은 Google Fonts Jua.
