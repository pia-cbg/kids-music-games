# 예종 음악 놀이터

예종피아노음악학원 초등학생(1~6학년)을 위한 음악 게임 모음입니다. 선생님 아이패드에서 쓰는 것을 기준으로 만들었고, 휴대폰에서도 동작합니다.
빌드 없는 정적 파일이라 GitHub Pages에 그대로 올려 씁니다.

## 게임 (학년별 난이도)

| 게임 | 1~3학년 | 4~6학년 |
|---|---|---|
| 🎼 계이름 맞히기 | 높은음자리표 도~도, 색깔 힌트 | 높은음·낮은음자리표, 덧줄 |
| 👂 높은 소리 낮은 소리 | 차이가 큰 두 소리 | 반음~3음 차이, "똑같아요" 포함 |
| 🥁 리듬 따라치기 | 4분·8분음표, 4분쉼표, 2분음표 | 점4분음표·당김음·엇박 |
| 🎹 건반 따라치기 | 도~솔 5건반 | 도~높은 도 8건반, 더 빠르게 |
| ⏱️ 몇 박일까요? | 온·2분·4분·8분음표, 쉼표 | 점음표·16분음표·여러 쉼표 |
| 🔍 건반 찾기 | 흰 건반 | 검은 건반(♯·♭)까지 |
| 🔣 음악 기호 퀴즈 | p·f, 도돌이표, 쉼표, 높은음자리표 | 셈여림·빠르기말·임시표·늘임표·스타카토 |
| 🎧 소리 듣고 계이름 | 도·미·솔 | 도~시 7음 |

별 1~3개, 연속 정답 콤보, 게임·학년별 최고 기록(기기에 저장)이 있습니다. 소리는 브라우저에서 합성합니다.

## 15분 놀이 시간 제한

- 게임을 처음 누른 순간부터 15분이 지나면 "오늘 놀이 시간 끝!" 화면으로 잠깁니다.
- 시작 시각을 기기에 저장해서 **새로고침하거나 다시 열어도 초기화되지 않습니다.**
- **선생님 해제**: 잠금 화면의 로고를 3초 동안 꾹 누르면 다음 학생이 새로 15분을 시작합니다.

## 실행

`index.html`을 열거나 `python3 -m http.server 8000`. 악보는 [VexFlow](https://www.vexflow.com/)(CDN), 글꼴은 Google Fonts Jua.
